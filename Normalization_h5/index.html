归一化方法全景 · Normalization

核心区分量：沿哪些轴计算 μ 和 σ —— 这决定了归一化的行为和适用场景

📐 归一化的统一形式

所有归一化方法共享同一个核心公式，区别仅在于 μ 和 σ 在哪些维度上计算。 输入张量形状为 (N, C, H, W)，不同的归一化方法沿不同的轴做规约。

🎯 各方法统计量计算轴

BN: 同一通道跨样本
LN: 同一样本跨通道
RMS: 同 LN 轴但不减均值
GN: 通道分组内
💡 核心直觉：归一化 = 在选定的"统计量共享区域"内计算 μ 和 σ，然后对该区域内每个元素做 (x−μ)/σ。 BN 的"区域"是跨样本同通道 → 依赖 batch 大小；LN 的"区域"是同样本跨通道 → 与 batch 无关，更适合序列模型。

Batch Normalization · 批归一化 (BN)

BN 在 (N, H, W) 维度上计算 μ 和 σ，每个通道 C 有独立的统计量。 同一通道的所有样本和空间位置共享 μ、σ。 问题：batch 太小时统计量不稳定；推理时需要 running_mean / running_var。

📐 BN 公式

💡 核心直觉：BN 让每个通道在 batch 内标准化 —— 相当于"白化"每个特征。 但 batch 太小（如 N=2）时 μ,σ 估计方差大，效果差。这就是为什么 BN 不适合小 batch 或变长序列。

Layer Normalization · 层归一化 (LN)

LN 在 (C, H, W) 维度上计算 μ 和 σ，每个样本 N 有独立的统计量。 与 batch 大小完全无关 —— 每个样本独立归一化。 优势：天然适合变长序列（NLP/Transformer），训练和推理行为一致。

📐 LN 公式

💡 核心直觉：LN 对每个样本独立归一化 → 天然适配 batch size=1 和变长序列。 Transformer 中 LN 在每个 token 的特征维度上归一化：每个 token 向量独立地做 (x−μ)/σ。 这就是为什么所有 transformer 都用 LN。

RMS Normalization · 均方根归一化 (RMS Norm)

RMS Norm 是 LN 的简化版：只除以 RMS(x)，不减均值。 计算更快（省去均值计算和减法），效果与 LN 相当甚至更好，被 LLaMA、Gemma 等主流模型采用。

📐 RMS Norm 公式

💡 核心直觉：为什么可以不要均值减法？因为后续的线性层（权重矩阵乘法 + bias）可以吸收均值偏移。 RMS Norm = 只做"缩放归一化"，省去减法操作 → 更快、更简单，且实验证明效果不减。 LLaMA 论文明确指出 RMS Norm 简化了 LayerNorm 并降低了计算开销。

Group Normalization · 分组归一化 (GN)

GN 是 BN 和 LN 的折中：将 C 个通道分成 G 组，在每组内的 (C/G, H, W) 维度上计算 μ 和 σ。 每个样本 N 独立归一化，每组通道独立统计。优势：对小 batch 鲁棒，适合检测/分割等 vision task。

📐 GN 公式

💡 核心直觉：GN = 将通道分组，组内做 LN。G=1 → LN；G=C → IN（Instance Norm）。 GN 不依赖 batch 维度，对小 batch 鲁棒，在检测/分割任务中常优于 BN。 极端情况：G=C 时每个通道独立归一化 = Instance Norm（风格迁移常用）。

💡 选型指南：CV 分类用 BN（大 batch）；NLP/Transformer 用 LN 或 RMS Norm（变长序列）； 检测/分割/小 batch 用 GN；追求推理速度用 RMS Norm（LLaMA 系标配）。 核心原理一句话：不要让你想要的统计量依赖于一个你控制不了的维度（如 batch size）。
