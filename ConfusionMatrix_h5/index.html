💡 指标选择指南

不同场景下应优先关注哪些指标

🏥 医疗诊断 / 疾病筛查

优先 Recall (召回率) — 宁可误诊，不可漏诊。
漏掉一个癌症患者比误报一个健康人代价大得多。
也关注 NPV (阴性预测值) — 阴性结果是否可信。

📧 垃圾邮件检测

优先 Precision (精确率) — 不要把重要邮件标记为垃圾。
误杀一封老板的邮件比漏过滤一封垃圾邮件更严重。
配合 F1 Score 在二者间取得平衡。

🛡️ 欺诈检测 / 安防

需要同时关注 Precision 和 Recall。
漏掉欺诈 → 财务损失（需要高 Recall）
误报欺诈 → 客户投诉（需要高 Precision）
通常用 F2 Score (β=2) 偏重召回。

📊 不均衡数据集

不要用 Accuracy！正负比 1:99 时，全猜负类 Accuracy=99% 但毫无意义。
优先 F1 Score、Precision-Recall AUC、
MCC (Matthews相关系数) 等对不平衡鲁棒的指标。

🔍 混淆矩阵含义详解

直观理解四个象限的含义及实际影响

✅ TP (True Positive) 真正例

预测为正，实际也为正。模型正确识别出的正类样本。
例：模型判断患者有病，确实有病 ✅
TP 越高，召回率越高。

✅ TN (True Negative) 真负例

预测为负，实际也为负。模型正确排除的负类样本。
例：模型判断健康人没病，确实没病 ✅
TN 越高，特异度越高。

⚠️ FP (False Positive) 假正例 / Type I Error

预测为正，实际为负。模型误报——"狼来了"🐺。
例：模型说健康人有病，实际没病 ❌
FP 越高，精确率越低。误报越多。

❌ FN (False Negative) 假负例 / Type II Error

预测为负，实际为正。模型漏报——最危险的错误⚠️。
例：模型说患者没病，实际有病——耽误治疗 ❌
FN 越高，召回率越低。漏报越多。

📈 扩展指标与曲线

超越单一阈值的评估方法

📐 ROC 曲线 (Receiver Operating Characteristic)

横轴: FPR = FP/(FP+TN)  |  纵轴: TPR = Recall
曲线下面积 = AUC-ROC (Area Under Curve)
AUC = 1.0 → 完美分类；AUC = 0.5 → 随机猜测
适用于正负样本相对均衡的场景。

🔄 多分类问题的混淆矩阵

对于 N 个类别，混淆矩阵是 N×N 矩阵：
对角线 = 各类别的 TP（正确分类）
非对角线 = 误分类（A 被误判为 B）
Macro-F1: 每个类别独立计算 F1 再求平均
Micro-F1: 汇总所有类别的 TP/FP/FN 后计算
Weighted-F1: 加权平均，权重为各类别样本数
