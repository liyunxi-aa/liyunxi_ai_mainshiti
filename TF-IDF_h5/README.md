# TF-IDF · BM25 · Skip-Gram · Uni-Gram · CoW 交互可视化

文本表示方法从词频统计到语义向量的完整演进。

## 内容

- **TF-IDF**: 词频-逆文档频率，稀疏词袋模型的代表
- **BM25**: 概率检索框架，TF饱和 + 文档长度归一化
- **Uni-Gram**: 一元词袋模型，所有复杂方法的基线
- **Skip-Gram**: Word2Vec 词向量学习，分布假说
- **CoW**: 共现窗口矩阵，GloVe 的前身

## 使用

在浏览器中打开 `index.html`，通过滑块交互调整参数，观察各模型的公式和可视化变化。
