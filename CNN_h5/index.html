1. 卷积运算 — CNN 的核心操作

卷积（Convolution）是 CNN 的核心运算。一个小的卷积核（Kernel / Filter）在输入张量上 滑动，在每个位置计算逐元素乘积之和，生成输出特征图（Feature Map）。 这种局部连接 + 权重共享的设计使 CNN 天然适合处理图像等具有空间结构的数据。

🔑

局部连接（Local Connectivity）：每个输出神经元只连接输入的一个局部区域 （感受野），而非全连接。这极大减少了参数数量——一个 3×3 卷积核只有 9 个参数，而全连接可能有数十万。

🔑

权重共享（Weight Sharing）：同一个卷积核在整个输入上滑动， 所有位置共享同一组权重。这使 CNN 具有平移等变性（Translation Equivariance）——输入平移，输出也相应平移。

💡

为什么卷积有效？图像具有局部相关性——相邻像素高度相关，远处像素几乎无关。 卷积核天然利用这一先验：它在局部 patch 上提取特征（边缘、纹理、角点等）， 堆叠多层后，浅层检测简单特征，深层检测语义概念（眼睛、轮子、人脸等）。这称为特征的层级抽象。

💡

Same Padding 为什么重要？在深度 CNN 中，如果每层都在缩小， 几十层后特征图将缩至 1×1，无法继续卷积。Same Padding（如 ResNet 中的 3×3 conv + pad=1） 保持空间尺寸不变，允许构建任意深度的网络。这也是 VGG/ResNet 广泛使用 3×3 卷积的重要原因。

3. 多通道卷积

真实图像有多个通道（RGB 有 3 个，中间层可能有 64、128、256 个通道）。 每个卷积核的通道数必须等于输入的通道数，输出通道数等于卷积核的个数。

💡

1×1 卷积（Pointwise / Network in Network）：当 K_h=K_w=1 时，卷积退化为对每个位置所有通道的线性组合。 1×1 卷积不改变空间尺寸，只改变通道数。它被广泛用于： (1) 降维（如 ResNet bottleneck 中从 256→64 通道）； (2) 增加非线性（后接 ReLU）； (3) 参数高效的特征变换（Depthwise Separable Convolution 的关键组成部分）。

4. 池化层（Pooling）— 降采样

池化层在特征图上做降采样（Downsampling），减小空间尺寸、增大感受野、降低计算量。 它没有可学习参数，仅对每个局部窗口做固定的聚合操作。 最常见的两种：最大池化（Max Pooling）和平均池化（Average Pooling）。

🔴

Max Pooling：取窗口内最大值。直觉：保留最强的激活信号（如边缘检测器的最强响应）。 提供局部平移不变性——特征在小范围内移动时，最大值位置可能不变，输出保持一致。 这是 CNN 中最常用的池化方式。

🔵

Average Pooling：取窗口内平均值。直觉：对局部区域做平滑， 保留整体强度信息而非单个峰值。在网络末端常用 Global Average Pooling (GAP) 将 H×W 特征图直接压缩为 1×1，替代全连接层——极大减少参数且防止过拟合。

💡

Global Average Pooling (GAP) 的巧妙之处：将 H×W×C 的特征图直接平均为 1×1×C 的向量， 每个通道对应一个类别的响应强度，直接送入 Softmax 分类。NIN（Network in Network）和 ResNet 都使用 GAP 替代 Flatten + FC，零参数、天然抗过拟合、且与输入尺寸无关（全卷积网络的关键设计）。

5. 感受野（Receptive Field）

感受野是指输出特征图上一个像素"看到"的原始输入区域大小。 随着卷积层和池化层堆叠，感受野逐步增大——浅层看到局部细节，深层看到全局语义。 这也是为什么现代 CNN（如 VGG）偏好堆叠小卷积核（3×3）而非大卷积核（7×7, 11×11）。

为什么堆叠小卷积核更好？两层 3×3 卷积的感受野 = 一层 5×5 卷积（都是 5×5），但： (1) 参数更少：2×(3²C²) vs 1×(5²C²) → 18 vs 25（减少 28%）； (2) 非线性更多：两次 ReLU 带来更强的表达能力； (3) 正则化效果：分解为两步约束了学习过程，相当于隐式的低秩正则。 VGG 证明了这一策略的有效性——更深 + 更小的卷积核 = 更好的性能。

📐 残差连接公式

💡

残差连接为什么是革命性的？在 ResNet 之前，网络加深到 20+ 层时训练误差反而上升 （退化问题，非过拟合）。残差连接让网络学习 F(x) = H(x) - x（残差），而非直接学习 H(x)。 如果恒等映射是最优的，残差块只需将 F(x) 推到 0——这比学习恒等映射容易得多。 残差连接也让梯度可以通过跳跃连接直接回传，使训练 152 层甚至 1000+ 层的网络成为可能。

7. 目标检测 — R-CNN 家族演进

CNN 不仅用于图像分类，在目标检测（Object Detection）领域同样取得了革命性突破。 从 R-CNN 到 Faster R-CNN，核心创新在于将区域提议、特征提取、分类回归逐步统一为端到端的可微系统。 这一演进完美诠释了"从 pipeline 到 end-to-end"的深度学习设计哲学。

📐 RPN (Region Proposal Network) — 锚点机制

🐢

R-CNN 的瓶颈：每张图需对 ~2000 个候选区域分别运行 CNN 前向传播， 训练耗时数天，推理一张图需 47 秒。Selective Search 本身也是 CPU 瓶颈， 且不可微，无法与 CNN 联合优化。

⚡

Fast R-CNN 的改进：整张图只跑一次 CNN，然后通过 RoI Pooling 在共享特征图上提取各区域的固定尺寸特征。训练速度提升 9×，推理 0.3 秒/图。 Softmax + BBox 回归的多任务损失替代了 SVM。

🚀

Faster R-CNN 的核心突破 — RPN：在共享特征图上加一个全卷积网络（RPN）， 直接预测区域提议。每个滑动位置预测 k 个锚点框（3 种尺寸 × 3 种比例 = 9 个锚点）， 输出 "有无物体" + "框修正量"。整个系统首次实现完全可微、端到端训练，推理速度接近实时（~0.2 秒/图）。

🎯

Mask R-CNN — RoIAlign 的精度提升：RoI Pooling 的两次量化取整造成像素级 misalignment。 RoIAlign 使用双线性插值在浮点坐标精确采样，消除量化误差。额外增加的Mask 分支 （FCN）为每个 RoI 预测二值分割掩码，使 Faster R-CNN 从目标检测扩展为实例分割框架。

8. 轻量化 CNN — MobileNet 系列

将 CNN 部署到移动端和嵌入式设备需要极致的参数和计算效率。 MobileNet 的核心创新是深度可分离卷积（Depthwise Separable Convolution）， 将标准卷积分解为两层：逐通道的空间卷积 + 逐点的通道融合，在几乎不损失精度的前提下将计算量降至 1/8 ~ 1/9。

🔄

Inverted Residual（倒残差）：传统 ResNet 瓶颈是"降维→卷积→升维"。 MobileNet v2 反过来——先 1×1 升维（6×）→ 3×3 深度卷积 → 1×1 降维。 直觉：深度卷积在高维空间能提取更丰富的特征，且跳跃连接在低维两端 （Linear Bottleneck），避免 ReLU 在低维造成信息损失。

🎛️

两个超参数 — Width Multiplier & Resolution Multiplier： α（Width Multiplier）：均匀缩放每层的通道数，{1.0, 0.75, 0.5, 0.35}，计算量 ≈ α²； ρ（Resolution Multiplier）：缩放输入分辨率，{224, 192, 160, 128}，计算量 ≈ ρ²。 二者结合可在精度-速度-模型尺寸三维度灵活权衡，适配不同硬件约束。

💡

为什么深度可分离卷积有效？标准卷积同时做空间滤波 + 通道融合， 而这两个操作可以解耦：先对每个通道独立做空间滤波（Depthwise）， 再用 1×1 卷积做通道间的线性组合（Pointwise）。这种分解基于一个关键假设： 空间相关性和通道相关性是可分离的。实践证明这一假设很有效—— 计算量从 O(K²·M·N) 降至 O(K²·M + M·N)，在 K=3, N≫M 时节省约 9 倍。 类似思想也出现在ShuffleNet（通道混洗替代 1×1 卷积）、 EfficientNet（NAS 搜索最优深度/宽度/分辨率比例）。

9. 从 CNN 到 Transformer — Swin Transformer

2020 年 ViT（Vision Transformer） 首次将纯 Transformer 架构应用于图像分类， 证明了 Transformer 可以替代卷积。但 ViT 有两个局限：(1) 所有层使用固定分辨率，计算量随图像尺寸平方增长； (2) 全局自注意力对密集预测任务（检测、分割）计算量不可承受。 Swin Transformer（2021）通过层次化设计 + 移位窗口注意力完美解决了这些问题。

📐 移位窗口自注意力

🏗️

层次化设计 — CNN 的"结构先验"：Swin Transformer 的 4 个 Stage 分辨率依次减半、通道数依次翻倍，这完全复刻了 CNN（如 ResNet）的层级设计。 Patch Merging 等价于 CNN 中的 stride=2 降采样。这使得 Swin 天然适配 FPN（特征金字塔）等多尺度架构，可以直接替换检测/分割任务中的 CNN backbone。

🪟

移位窗口的巧妙之处：标准窗口自注意力每个窗口独立计算，窗口之间没有信息交互。 Swin 通过交替使用常规窗口和移位窗口，让相邻窗口的信息在下一层得以交互。 计算复杂度从 ViT 的 O((HW)²) 降至 O((HW)·M²)，其中 M 是窗口大小（默认 7）， 使 Transformer 可以处理任意分辨率的图像。

特性 ViT (2020) Swin Transformer (2021)
分辨率 全层固定（如 14×14） 层次化：H/4 → H/8 → H/16 → H/32
注意力范围 全局自注意力（所有 patch） 局部窗口注意力 + 移位窗口跨窗口交互
计算复杂度 O((HW)²) — 二次方 O((HW)·M²) — 线性（M=7 固定）
检测/分割任务 需额外适配（如特征金字塔） 天然兼容 FPN / U-Net 等多尺度架构
相对位置编码 可学习绝对位置编码 相对位置偏置（Relative Position Bias）
💡

Swin Transformer 的启示 — CNN 与 Transformer 的融合：Swin 的成功表明， 纯 Transformer 并不必须抛弃 CNN 的设计智慧。层次化、局部性、平移等变性这些 CNN 的结构先验被融入 Transformer 后，反而获得了更强的性能。 此后的ConvNeXt（2022）反向借鉴 Swin 的设计（GELU、LayerNorm、大卷积核）， 用纯卷积达到了与 Swin 相当的性能，证明了架构思想比具体操作更重要。 两者的融合趋势还在加速：DeiT（蒸馏）、PVT（金字塔 ViT）、 CSWin（十字窗口）等都是这一方向的重要探索。

📋 计算机视觉（CV）面试题精讲

涵盖 CNN 基础、残差网络、ViT、目标检测、模型压缩等核心考点，点击展开答案

🔷 CNN 基础结构
1. CNN 的基础结构由哪些部分组成？ ▼
三大核心组件：
• 卷积层（Convolution Layer）：通过卷积核提取局部特征，卷积核常用奇数尺寸（3×3、5×5、7×7）以保证中心对称；
• 池化层（Pooling Layer）：下采样降维，常见的有最大池化（Max Pooling）和平均池化（Avg Pooling）；
• 全连接层（Fully Connected Layer）：将提取的特征映射到分类/回归输出。

卷积输出尺寸公式：输入 m×n，卷积核 k×k，步长=1，无padding → 输出 (m-k+1)×(n-k+1)。带padding：输出 = ⌊(m+2p-k)/s⌋ + 1。
2. 卷积核为什么通常使用奇数尺寸？ ▼
奇数卷积核（如3×3、5×5）具有明确的中心点，便于对齐和对称padding。偶数卷积核没有唯一中心，会导致特征图偏移。此外，3×3卷积核堆叠可以获得与更大卷积核相同的感受野，但参数量更少。
3. 池化层的作用是什么？ ▼
• 降维：减少特征图尺寸，降低计算量和参数量；
• 平移不变性：对微小位置变化不敏感；
• 防止过拟合：通过下采样减少特征维度；
• 扩大感受野：让后续层能看到更大范围的输入。
🔷 残差网络 ResNet
4. ResNet 的核心思想是什么？为什么它能训练上百层？ ▼
核心思想：跳跃连接（Skip Connection / Shortcut）
输出 = F(x) + x，其中F(x)为残差映射，x为恒等映射。

为什么有效：
• 梯度可直接通过恒等路径回传（梯度高速公路），解决深层网络的梯度消失问题；
• 将学习目标从完整映射H(x)转变为残差F(x)=H(x)-x，降低了优化难度；
• 即使新增层什么也不学（F(x)≈0），模型性能也不会退化（至少等于浅层网络）。
🔷 ViT（视觉Transformer）
5. ViT（Vision Transformer）的完整流程是怎样的？ ▼
处理流程：
1. 图像分块（Patch Partition）：将图像切分为固定大小的Patch（如16×16）；
2. 线性投影（Patch Embedding）：将每个Patch展平并通过线性层映射为向量；
3. 添加 [CLS] Token + 位置编码：在序列开头拼接可学习的分类token，加上可学习位置编码；
4. Transformer Encoder：多层多头自注意力 + FFN 处理；
5. 分类头：取[CLS] token的输出做分类。

优势：全局建模能力强，摆脱CNN的局部感受野限制，适合大规模数据训练。
6. ViT 相比 CNN 有什么优势和劣势？ ▼
优势：
• 全局自注意力，无局部感受野限制；
• 更强的可扩展性（模型越大、数据越多，性能提升越明显）；
• 统一的架构，多模态更容易融合。

劣势：
• 缺少CNN天然的归纳偏置（局部性、平移不变性），小数据上效果不如CNN；
• 计算复杂度O(n²)，高分辨率图像计算量大；
• 需要更多训练数据才能发挥优势。
🔷 目标检测
7. IoU / GIoU / CIoU 分别是什么？ ▼
• IoU（Intersection over Union）：预测框与真实框的交并比，最基础的检测框度量；
• GIoU（Generalized IoU）：引入最小外接矩形，解决IoU在框不相交时为0的问题；
• CIoU（Complete IoU）：额外考虑中心点距离和长宽比，更全面衡量框的匹配质量。
DIoU（Distance IoU）是中间版本，仅加入中心点距离。
8. NMS（非极大值抑制）的工作原理是什么？ ▼
NMS（Non-Maximum Suppression）算法流程：
1. 按置信度对所有检测框降序排列；
2. 选置信度最高的框加入结果集；
3. 计算其余框与该框的IoU，删除IoU超过阈值（如0.5）的框；
4. 重复步骤2-3直到所有框处理完毕。

目的：去除同一目标上的重复检测框，保留最优的那个。
9. 主流目标检测算法有哪些？ ▼
• YOLO系列：单阶段检测器，速度快，将检测视为回归问题（直接预测框和类别）；
• Faster R-CNN：两阶段检测器，先RPN生成候选区域再精细分类；
• SSD：单阶段多尺度检测；
• Swin-Transformer：将Transformer引入视觉骨干网络，用于检测等下游任务；
• EAST：专门用于文本检测的模型。
🔷 模型压缩与加速
10. 模型压缩与加速有哪些主流方法？ ▼
• 剪枝（Pruning）：移除不重要的权重/神经元/通道，减少模型大小；
• 量化（Quantization）：将FP32权重转为INT8/INT4，降低计算和存储开销；
• 知识蒸馏（Knowledge Distillation）：用大模型（Teacher）指导小模型（Student）训练；
• 深度可分离卷积（Depthwise Separable Convolution）：将标准卷积拆为深度卷积+逐点卷积，参数量大幅减少（MobileNet）；
• 混合精度训练（Mixed Precision）：FP16/FP32混合使用，加速训练并节省显存。
11. 深度可分离卷积与标准卷积有什么区别？ ▼
标准卷积：同时对空间和通道进行卷积，参数量 = Dₖ×Dₖ×M×N（M输入通道，N输出通道）。

深度可分离卷积：
① Depthwise卷积：每个通道独立做空间卷积，参数量 = Dₖ×Dₖ×M；
② Pointwise卷积：1×1卷积融合通道信息，参数量 = M×N。
总参数量 = Dₖ×Dₖ×M + M×N，约为标准卷积的 1/N + 1/Dₖ²，大幅减少。
🔷 半监督 / 自监督 / 无监督学习
12. 半监督、自监督、无监督学习有什么区别？ ▼
• 无监督学习：完全无标注数据，挖掘数据内在结构（如聚类、降维）；
• 半监督学习：少量标注+大量无标注数据联合训练（如FixMatch），利用无标注数据提升泛化；
• 自监督学习：利用数据自身构造监督信号（Pretext Task），如SimCLR对比学习、MAE掩码重建，无需人工标注即可学习高质量表示。

自监督学习是当前CV领域的重点方向，ViT的成功很大程度上得益于大规模自监督预训练。
