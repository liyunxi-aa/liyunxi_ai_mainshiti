# 🧊 LayerNorm vs BatchNorm — 3D 魔方矩阵可视化

一个基于 **Three.js** 的交互式 3D 可视化工具，用"魔方矩阵"直观展示 BatchNorm 和 LayerNorm 的计算过程差异。

## 🎯 核心概念

| 维度 | BatchNorm (BN) | LayerNorm (LN) |
|------|---------------|----------------|
| **计算方向** | 🔵 **竖着算** — 同一特征，全部样本 | 🟢 **横着算** — 同一样本，全部特征 |
| **统计维度** | 跨 batch 维度 (N) | 跨 feature 维度 (D) |
| **μ, σ 计算** | 每个特征独立的 μ, σ | 每个样本独立的 μ, σ |
| **典型应用** | 图像 CNN (Conv → BN → ReLU) | NLP Transformer (Self-Attn → LN) |
| **依赖** | 依赖 batch size | 不依赖 batch size |

## 🕹️ 操作方式

| 操作 | 说明 |
|------|------|
| 🖱️ **拖拽** | 旋转 3D 视角 |
| 🖱️ **滚轮** | 缩放 |
| 🖱️ **右键拖拽** | 平移 |
| 🖱️ **点击方块** | 切换高亮的特征列/样本行 |
| ⌨️ **B / L** | 切换到 BN / LN 模式 |
| ⌨️ **← →** | 切换高亮的特征/样本索引 |
| ⌨️ **↑ ↓** | 切换计算步骤 |

## 📐 计算步骤

0. **原始矩阵** — 查看 4×8 的原始数据矩阵
1. **计算均值 μ** — 对高亮区域求算术平均
2. **计算方差 σ²** — 对高亮区域求方差
3. **归一化** — x̂ = (x - μ) / √(σ² + ε)
4. **缩放平移** — y = γ · x̂ + β（可学习参数）

## 🎨 色彩编码

- 🔵 **蓝色系** — BatchNorm 列 (特征维度)
- 🟢 **绿色系** — LayerNorm 行 (样本维度)
- 🔴 **暖色系** — 高数值
- 🔵 **冷色系** — 低数值
