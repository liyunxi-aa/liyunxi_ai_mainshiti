🔄 经典 S 型激活函数

Sigmoid 和 Tanh 是最早广泛使用的激活函数，具有平滑、有界的 S 形曲线。但由于梯度消失问题，现主要用于特定场景（输出层、门控机制）。

Sigmoid

📦 输出: (0, 1) ⚡ 计算: ★★ ⚠️ 梯度消失 ✅ 二分类输出

Tanh

📦 输出: (-1, 1) 🎯 零中心 ⚡ 计算: ★★ ✅ RNN/LSTM

Softsign

📦 输出: (-1, 1) 🎯 零中心 ⚡ 无 exp ⚠️ 小众选择

💡 核心直觉

Sigmoid 输出恒正（非零中心），导致后续层输入的 zig-zag 梯度更新；Tanh 虽为零中心，但两者的饱和区梯度几乎为零，深层网络难以训练。现代深度网络几乎不在隐藏层使用它们。

⚙️ ReLU 家族

ReLU 是深度学习中最广泛使用的激活函数家族。从基础 ReLU 到各种改进变体（Leaky ReLU、ELU、SELU 等），核心目标都是解决 ReLU 的"神经元死亡"问题。

ReLU

✅ 通用推荐⚠️ 神经元死亡

ReLU-6

✅ 移动端📦 输出 [0,6]

Leaky ReLU

✅ 缓解死亡🔧 α=0.01

PReLU

🔧 α 可学习⚠️ 易过拟合

ELU

✅ 深层推荐⚡ 含 exp

SELU

🎯 自归一化⚠️ 仅全连接

CELU

✅ 处处可导⚡ 含 exp

Softplus

📦 输出正数⚡ 含 exp+log

💡 核心直觉

ReLU 的"死亡"源于负半轴梯度为 0——一旦神经元落入负激活区，就不再更新。Leaky ReLU 用微小斜率 (α=0.01) 保留梯度流；ELU 用指数函数使负输出近零中心；SELU 更进一步，通过精心设计的 λ 参数实现自归一化。

🌟 平滑激活函数（现代模型首选）

GELU、Swish/SiLU、Mish 等平滑激活函数在 Transformer 和现代 CNN 中表现优异。它们具有平滑的梯度和非单调特性，但计算成本较高。

GELU

✅ Transformer📊 有理论依据

Swish / SiLU

✅ 替代 ReLU🔧 β 可调

HardSwish

✅ 移动端⚡ 无 exp

Mish

⚠️ 研究用途⚡ 计算极重

TanhExp

❌ 不推荐⚡ 不稳定

Softsign

⚠️ 不推荐主流⚡ 无 exp

💡 核心直觉

GELU 通过将输入乘以标准正态 CDF Φ(x) 实现"概率性"门控——小输入更可能被抑制，大输入更可能通过。Swish 用 Sigmoid 实现类似效果。两者的非单调"凹陷"（约在 x≈-1 处）被认为是性能优势的关键，允许梯度在负区域有更丰富的表达。

🚪 门控线性单元 (GLU Family)

GLU 引入了门控机制：将输入分成两路，一路做线性变换，另一路通过激活函数做门控。SwiGLU 是当前 LLM（如 Llama）中最主流的激活函数。

GLU

✅ Transformer FFN⚠️ 参数翻倍

ReGLU

⚡ 计算快⚠️ 不够平滑

GeGLU

✅ T5, PaLM⚡ 计算重

SwiGLU 🏆

✅ Llama 首选⚡ 性能最优

💡 核心直觉

GLU 的核心思想是"学习哪些信息可以通过"。门控路径 (σ(Wgx)) 输出 0~1 的权重，逐元素控制线性路径的输出。SwiGLU 将门控激活替换为 Swish，在 LLM 中表现最佳——Llama 系列模型全部采用 SwiGLU 作为 FFN 激活函数。

📱 部署优化激活函数

针对边缘设备、移动端和量化模型的轻量级激活函数，牺牲少量精度换取推理速度和硬件友好性。

LUT-based (查表法)

⚡ 极速推理💾 内存占用✅ FPGA/边缘

QuantReLU

📦 低比特🔧 STE 近似梯度✅ 工业部署

💡 核心直觉

LUT 将激活函数预计算为离散查找表，推理时只需 O(1) 查表；QuantReLU 将连续值量化为整数倍，大幅降低存储和计算需求。两者都依赖量化感知训练 (QAT) 弥补精度损失。

🏆 总结与推荐

✅ 通用隐藏层首选

基础选择：ReLU — 简单高效
进阶选择：GELU / Swish — Transformer 标配
防死亡：Leaky ReLU / ELU — 深层网络

✅ LLM / Transformer

FFN 激活：SwiGLU（Llama 首选）
注意力头：Softmax（不可替代）
位置编码：无需激活或 Linear

✅ 移动端 / 边缘部署

轻量 CNN：ReLU-6 / HardSwish
量化模型：QuantReLU
FPGA/嵌入式：LUT-based

⚠️ 仅限特定场景

Sigmoid：二分类输出、门控
Tanh：RNN/LSTM 隐藏状态
Linear：回归输出、残差连接

⚠️ 实验/不推荐

Mish：视觉任务实验
TanhExp：计算极重且不稳定
Softsign：小众、表达能力弱
PReLU：易过拟合、不稳定

📐 选型决策流程

1. Transformer FFN → SwiGLU
2. 通用 CNN/MLP → ReLU 或 GELU
3. 移动端 → HardSwish / ReLU-6
4. 二分类输出 → Sigmoid
5. 多分类输出 → Softmax
