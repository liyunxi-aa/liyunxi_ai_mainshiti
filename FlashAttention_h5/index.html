⚡ FlashAttention · IO-Aware 精确注意力

通过分块计算 + 在线 Softmax + Kernel Fusion，将标准注意力的 HBM 读写从 O(N²d) 降至 O(N²d²/M)，实现 2-4× 加速与显存节省

1. 问题：标准注意力的显存瓶颈

标准 attention 计算 S = QKᵀ ∈ RN×N，必须在 HBM 中存储完整的 N×N 注意力矩阵， 然后进行 softmax 并乘 V。当序列长度 N 较大（≥2K）时，O(N²) 的显存开销成为核心瓶颈。

📐 标准 Attention

💡 核心瓶颈：中间矩阵 S = QKᵀ 大小为 N×N，以 fp16 计，N=4096 时 仅这一项就占用 32 MB。 实际训练中 batch_size × num_heads 会让这个数字放大多倍。FlashAttention 的目标：不把这个矩阵写入 HBM。

2. 分块策略 (Tiling) — 让计算留在 SRAM

核心思想：将 Q 分成 Tr 个块，K/V 分成 Tc 个块， 每次只将一个 Q 块与所有 K/V 块依次处理。计算在高速 SRAM (on-chip) 中完成， 只把最终结果写回 HBM，中间注意力矩阵从不完整写入 HBM。

📐 分块表示

💡 SRAM vs HBM：A100 GPU 中，HBM 带宽 ~1.5-2.0 TB/s 但延迟高；SRAM 每 SM 仅 ~192KB 但速度极快（~19 TB/s）。 FlashAttention 将注意力矩阵 S 的读写从 O(N²) 降为分块访问，每个 S 分块仅在 SRAM 中短暂存在。

3. 在线 Softmax — 逐块数值稳定计算

标准 softmax 需要三次遍历（max → exp → sum → normalize）。 在线 softmax 通过 维护 running max 和 running sum， 在每块到达时动态 "修正" 之前的累计值，实现单次遍历完成 softmax。

📐 在线 Softmax 递推公式

💡 关键技巧：当新的最大分数 mnew 比旧的 mold 大时，之前的 exp 值需要 "缩小"： Pold · exp(mold − mnew)。 这正是数值稳定的 softmax 实现中减 max 的增量版本。

4. 前向传播：完整算法流程

FlashAttention 前向传播将上述分块与在线 softmax 结合，逐块计算 O = softmax(QKᵀ/√d)V。 每个 Q 块遍历所有 K/V 块，在 SRAM 中完成整个 softmax + 加权求和。

// FlashAttention Forward Pass for i = 1 to Tr: // Q 块循环 (外层) load Qi from HBM → SRAM // Q[i*B_r : (i+1)*B_r, :] Oi = (0)B_r×d ℓi = mi = (−∞)B_r for j = 1 to Tc: // K/V 块循环 (内层) load Kj, Vj from HBM → SRAM Sij = Qi KjT // [B_r × B_c] on-chip m̃ij = rowmax(Sij) P̃ij = exp(Sij − m̃ij) // safe exp ℓ̃ij = rowsum(P̃ij) minew = max(mi, m̃ij) // 更新 running max ℓinew = e(mi−minew) ℓi + e(m̃ij−minew) ℓ̃ij // 修正旧的 sum Oi = diag(e(mi−minew)) Oi + e(m̃ij−minew) P̃ij Vj mi = minew ℓi = ℓinew Oi = diag(ℓi−1) Oi // 最终归一化 write Oi → HBM write mi, ℓi → HBM // 保存给 backward end

💡 两个嵌套循环 = 两层 tiling：外层遍历 Q 块、内层遍历 K/V 块。 每个 Q 块完成后，它的输出 Oi 就确定了，可以立即写回 HBM。 中间矩阵 Sij 只在 SRAM 中存在，立刻被消费并丢弃。

5. 反向传播：重计算代替存储

因为前向没有保存完整的 S = QKᵀ 矩阵，反向传播时必须 重新计算 Sij。 但利用前向保存的 mi 和 ℓi（每 Q 块仅需 Br 个 float）， 可以直接重建 softmax 归一化的 P = diag(ℓ−1) exp(S − m)，无需再遍历 max/sum。

📐 重计算公式 (给定 dO, Q, K, V, m, ℓ)

💡 内存节省的本质：标准注意力需存储 N×N 矩阵用于反向（fp16: N²×2 bytes）。 FlashAttention 仅需存储每 Q-block 的 m 和 ℓ（总共 N×2 floats）。 N=4096 时：128MB vs 32KB — 相差 4000 倍。

6. IO 复杂度对比与总结

FlashAttention 通过分块计算将 HBM 读写量从 O(Nd+N²) 降至 O(N²d²M−1)。 当 SRAM 大小 M = 100KB、d=64 时，标准 Attention 的 HBM 读写 ≈ FlashAttention 的 4-8 倍。
