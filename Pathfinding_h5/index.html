三、算法核心原理

⭐ A* 算法 — 启发式搜索的黄金标准

A* 的核心思想：在 Dijkstra 的"已走代价优先"和贪心搜索的"剩余代价优先"之间取得最优平衡。 当 h(n) 是可采纳的（不高估真实代价）且一致的（满足三角不等式），A* 保证找到最优路径。 曼哈顿距离在 4 方向网格中是一致启发式；对角线距离在 8 方向网格中是一致启发式。

⚖️ Dijkstra vs 贪心最佳优先 — 两个极端

📐 启发函数详解

💡 核心直觉： 路径搜索算法本质上是探索策略的权衡。 Dijkstra 像水波扩散，保证最优但慢；贪心搜索直奔目标，快但可能绕远路；A* 两者兼顾，是最实用的选择。 选择启发函数时，越接近真实剩余距离（但不高估），搜索效率越高。

四、A* 算法伪代码

以下伪代码展示了 A* 搜索的核心流程。实际运行时可观察每一步对应伪代码的哪一行。

1. 初始化：将起点加入 openSet，g[start]=0, f[start]=h(start, goal)
2. while openSet 非空:
3. current = openSet 中 f 值最小的节点
4. if current == goal: 找到路径，回溯 reconstruct_path
5. 将 current 从 openSet 移除，加入 closedSet
6. for each neighbor of current:
7. if neighbor in closedSet 或 是墙壁: continue
8. tentative_g = g[current] + dist(current, neighbor)
9. if tentative_g < g[neighbor]:
10. neighbor.parent = current
11. g[neighbor] = tentative_g
12. f[neighbor] = g[neighbor] + h(neighbor, goal)
13. if neighbor not in openSet: 加入 openSet
14. 未找到路径，返回失败

五、五种算法性质对比

不同算法在最优性、完备性和效率之间的权衡，决定了它们的适用场景。

算法 评价函数 数据结构 最优性 完备性 时间复杂度 适用场景
A* ⭐ f(n)=g(n)+h(n) 优先队列 (二叉堆) ✅ (h 可采纳) ✅ O(b^d) 游戏寻路、机器人导航、地图路由
Dijkstra f(n)=g(n) 优先队列 (二叉堆) ✅ ✅ O((V+E)\log V) 网络路由 (OSPF)、地图最短路径
贪心最佳优先 f(n)=h(n) 优先队列 (二叉堆) ❌ ✅ (有限图) O(b^m) 快速近似解、有较好启发式的场景
BFS 先进先出 (FIFO) 队列 (Queue) ✅ (无权图) ✅ O(V+E) 无权图最短路径、社交网络度数
DFS 后进先出 (LIFO) 栈 (Stack) ❌ ✅ (有限图) O(V+E) 迷宫生成、拓扑排序、连通分量
