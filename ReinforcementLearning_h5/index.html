一、马尔可夫决策过程 (MDP)

强化学习的数学基础是马尔可夫决策过程 (MDP)——一个由五元组 (S, A, P, R, γ) 定义的框架。 Agent 在环境中通过试错 (Trial-and-Error) 学习：观察状态 s，执行动作 a，获得奖励 r，并转移到新状态 s'。 目标是找到最优策略 π* 以最大化累计折扣奖励。

📐 MDP 五元组定义

🎯 价值函数 V(s)

🎯 动作价值函数 Q(s,a)

💡 核心直觉：V(s) 衡量"站在状态 s 上有多好"，而 Q(s,a) 衡量"在状态 s 执行动作 a 有多好"。 Q 函数比 V 函数多了一个动作维度——这正是 Q-Learning 能够直接从中提取最优策略（贪心选取最大 Q 值的动作）的关键原因。

二、Bellman 方程 — 递归分解的核心

强化学习的核心数学工具是 Bellman 方程，它将一个状态的价值递归分解为即时奖励加上后继状态的折扣价值。 Bellman 最优方程进一步给出了最优价值函数必须满足的条件，这是 Q-Learning 和 Value Iteration 的理论基础。

📐 Bellman 期望方程 → Bellman 最优方程

⚡ TD 更新规则 — Q-Learning 的核心

💡 核心直觉：TD 误差 δ = r + γ·max Q(s',a') − Q(s,a) 衡量"实际收到的比你预期的多多少"。 如果 δ > 0（惊喜），提高 Q(s,a)；如果 δ < 0（失望），降低 Q(s,a)。 这就是 Agent 从试错中学习的基本机制——与人类从"预期偏差"中学习的方式高度一致。

三、Q-Learning 算法

Q-Learning 是最经典的 无模型 (Model-Free)、离策略 (Off-Policy) 强化学习算法。 它直接学习最优 Q 函数 Q*(s,a)，而不需要知道环境的状态转移概率 P(s'|s,a)。 通过 ε-贪心策略 平衡探索与利用，Q-Learning 在表格型（离散状态/动作）问题上保证收敛到最优策略。

Algorithm: Tabular Q-Learning
1. 初始化 Q(s,a) ← 0 for all s ∈ S, a ∈ A
2. for episode = 1, 2, ..., M do:
3.   s ← 初始状态 (agent 回到起点)
4.   while s 不是终止状态 do:
5.     a ← ε-贪心选择: 以概率ε随机选择，否则选 argmax_a Q(s,a)
6.     执行动作 a，观察奖励 r 和新状态 s'
7.     Q(s,a) ← Q(s,a) + α [ r + γ·max_a' Q(s',a') − Q(s,a) ]
8.     s ← s'
9.   end while
10. end for
💡 Off-Policy 的含义：Q-Learning 用行为策略（ε-贪心）来探索环境收集数据， 但更新时直接用 max_a' Q(s',a')（即最优贪心策略的估计）作为目标——它"在学习最优策略，即使自己并不按照该策略行动"。 这与 SARSA 的 On-Policy 形成鲜明对比，后者使用实际执行的动作 a' 来更新。

五、探索 vs 利用 — ε-贪心策略

强化学习的核心困境：Agent 应该探索 (Explore) 未知的状态-动作组合以发现更好的策略， 还是利用 (Exploit) 当前已知的最优动作以最大化即时奖励？ 最常见的折中方案是 ε-贪心 (ε-Greedy) 策略：

📐 ε-贪心策略定义

策略探索方式优点缺点
ε-贪心 以 ε 概率随机选择动作 简单、保证收敛 (ε→0) 随机探索效率低
ε-衰减 ε 随时间指数/线性衰减 早期多探索，后期多利用 需要调衰减速率
UCB (上置信界) 选 a 最大化 Q(s,a) + c·√(ln t / N(s,a)) 原则性探索，按不确定性加权 需要记录访问次数
Boltzmann (Softmax) 按 exp(Q(s,a)/τ) 概率采样 平滑概率分布，温度 τ 控制 温度 τ 难以调节
💡 关键洞察：如果 ε 恒为 0（从不探索），Q-Learning 可能永远找不到最优策略—— 因为它只会重复已知的路径，从不尝试可能更好的替代方案。 但 ε 太大则 Agent 的行为近乎随机，无法有效利用已学到的知识。 在实践中，ε 衰减（从高探索率开始，逐渐降低）是最常用的策略。

六、从表格 Q-Learning 到深度 Q 网络 (DQN)

当状态空间变得巨大（例如 Atari 游戏的像素画面）或连续时，表格 Q-Learning 不再可行。 Deep Q-Network (DQN) 使用深度神经网络来近似 Q 函数 Q(s,a; θ)，由 DeepMind 在 2013/2015 年提出， 标志着现代深度强化学习的开端。

🔗 强化学习算法演进

1. Q-Learning (1989) — 表格型，离策略，TD 学习
2. SARSA (1994) — 表格型，在策略，更保守（考虑探索风险）
3. DQN (2013/2015) — 深度网络 + Experience Replay + Target Network → Atari 人类水平
4. Double DQN (2016) — 解耦动作选择与评估，缓解 Q 值高估
5. Dueling DQN (2016) — 分离 V(s) 与 Advantage(s,a)，提升学习效率
6. A3C / A2C (2016) — Actor-Critic 架构，并行训练
7. PPO (2017) — 信任区域策略优化，约束策略更新幅度 → 最广泛使用的 RL 算法之一
8. SAC (2018) — 最大熵 RL，离线策略 Actor-Critic → SOTA 样本效率
💡 核心教训：DQN 的成功不在于算法本身多么复杂，而在于解决了深度神经网络与 RL 结合时的两个根本挑战： ① 样本之间高度相关（Experience Replay 打破相关性）；② 目标值随网络更新不断变化（Target Network 稳定目标）。 这两个技巧至今仍是绝大多数深度 RL 算法的标配。
