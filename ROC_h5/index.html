一、从混淆矩阵到 TPR & FPR

ROC（Receiver Operating Characteristic）曲线起源于二战雷达信号检测，现已成为评估二分类模型的核心工具。 其基础指标来自混淆矩阵：真正例率（TPR）和假正例率（FPR）构成了 ROC 空间的两个坐标轴。

💡 核心直觉：ROC 曲线的横轴 FPR 衡量「误报率」， 纵轴 TPR 衡量「正类检出率」。二者天然存在权衡 —— 降低阈值能检出更多正类（TPR↑），但也会让更多负类被误判（FPR↑）。

💡 关键观察：分布分离度越大（分类器越强），ROC 曲线越靠近左上角 (0,1) —— 完美分类点。 此时 AUC → 1。当两个分布完全重合时，ROC 曲线退化为对角线，AUC = 0.5，分类器无异于随机猜测。

三、AUC — 面积的含义与计算

AUC（Area Under the ROC Curve）是 ROC 曲线下的面积，取值范围 [0, 1]。 它有一个非常优雅的概率解释：随机选一个正样本和一个负样本，分类器给正样本的得分高于负样本的概率。

📐 AUC 的概率定义与计算公式

右侧展示了不同 AUC 值对应的 ROC 曲线形态。切换不同曲线以直观感受 AUC 的含义：

AUC 经验法则：
· 0.9–1.0 → 优秀
· 0.8–0.9 → 良好
· 0.7–0.8 → 一般
· 0.6–0.7 → 较差
· 0.5–0.6 → 接近随机
· = 0.5 → 随机猜测
· < 0.5 → 比随机还差（可取反）

💡 为什么 AUC 对类别不平衡不敏感？因为 TPR 和 FPR 都是列内比率（分别只关注正类和负类的内部构成）， 不依赖于正负样本的数量比例。因此即使正样本只占 1%，AUC 仍能公平评估模型排序能力。 但这同时也是 AUC 的局限 —— 当正类极其稀疏时，你可能更关心精准率而非 FPR，此时应辅以 PR 曲线（见第五节）。

四、多分类器 ROC 对比

在同一 ROC 空间中绘制多个分类器的曲线，是实践中常用的模型选择方法。哪个分类器的曲线「包住」其他曲线， 哪个分类器在所有可能的阈值下都更优。如果曲线交叉，则需要根据具体 FPR/TPR 需求权衡。

💡 曲线交叉意味着什么？如果随机森林在低 FPR 区域表现更好（更保守的场景）， 而逻辑回归在高 TPR 区域更优（更激进的场景），说明没有单一模型在所有场景下都是最优的。 实际部署时应根据业务对假阳性的容忍度选择合适的工作点（阈值）。

五、PR 曲线 — 类别不平衡时的补充视角

当正负样本严重不平衡时（如欺诈检测、罕见病诊断），ROC 曲线可能过于乐观。 Precision-Recall（PR）曲线聚焦于正类的预测质量，能更真实地反映模型在稀疏正类场景下的表现。

💡 关键教训：在极度不平衡的数据集上（正样本 < 1%），ROC-AUC 可能高达 0.95 但模型实际上几乎没有找到任何真正例。 永远在类别不平衡场景中同时审视 ROC 和 PR 曲线，PR-AUC 和 Average Precision (AP) 才能更真实地反映模型能力。

🧠 面试常见问题：
1. AUC = 0.8 意味着什么？ → 随机选一个正样本和一个负样本，分类器给正样本更高分数的概率是 80%。
2. 为什么用 ROC 而不用 Accuracy？ → Accuracy 受阈值和类别平衡影响，ROC/AUC 是阈值无关的整体评估。
3. ROC vs PR 曲线何时用哪个？ → 类别平衡或关心整体排序用 ROC；正类稀疏时 PR 更能暴露模型问题。
4. Gini 系数与 AUC 的关系？ → Gini = 2 × AUC − 1，在金融风控领域更常用。
