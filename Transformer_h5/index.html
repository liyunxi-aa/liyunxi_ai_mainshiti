2017 年 Vaswani 等人提出 Transformer（"Attention Is All You Need"），完全抛弃循环结构； 2018 年 BERT（Encoder-only）和 GPT（Decoder-only）分别占据理解和生成赛道； 2019 年 T5 统一为 Text-to-Text 框架；2020 年后 Decoder-only Transformer 成为 LLM 主流架构。

1. 整体架构 — Encoder-Decoder

Transformer 由 N 层编码器（Encoder）和 N 层解码器（Decoder）堆叠而成 （原论文 N=6）。编码器将输入序列映射为连续表示，解码器基于编码器输出自回归地生成目标序列。 每个 Encoder/Decoder 层内部由 Multi-Head Attention、Feed-Forward Network 和 Add & LayerNorm（残差连接 + 层归一化）组成。

核心直觉：Encoder 是双向的——每个 token 可以关注所有其他 token（包括前后），适合理解任务。 Decoder 是单向的（自回归）——每个 token 只能关注它之前的 token（含自己），适合生成任务。 Cross-Attention 桥接两者：Decoder 的 Q 查询 Encoder 的 K/V，让生成过程"看到"输入序列的完整上下文。

2. 输入处理 — Token Embedding + Positional Encoding

Transformer 本身没有循环或卷积结构，因此无法感知 token 的顺序。为了让模型知道"谁在前、谁在后"， 必须在输入中注入位置信息。输入表示 = Token Embedding + Positional Encoding（两者相加，维度均为 d_model）。

3. Self-Attention — 自注意力机制深度解析

Self-Attention 是 Transformer 的核心创新。它让序列中的每个 token 都能直接关注 序列中的所有其他 token，计算一个加权和作为自己的上下文表示。相比 RNN 的 O(n) 路径长度， Self-Attention 的任意两个 token 之间路径长度为 O(1)，极大缓解了长距离依赖问题。

💡

直觉理解：把 Self-Attention 想象成一次"数据库查询"—— Query（查询）：当前 token "我要找什么信息？"
Key（键）：每个 token "我能提供什么信息？"
Value（值）：每个 token "我实际存储的信息是什么？"
Q 与所有 K 做点积得到"匹配分数"，经过 Softmax 归一化后成为"注意力权重"，最后对 V 加权求和。 每个 token 都会根据自身需求从整个序列中聚合不同侧重的信息。

4. Multi-Head Attention — 多头注意力

单一的 Self-Attention 只能捕获一种"关系模式"。Multi-Head Attention 将 Q/K/V 分别投影到 h 个不同的低维子空间（原论文 h=8, d_k=d_v=64），在每个子空间中独立计算注意力， 最后拼接并投影回 d_model 维度。这让模型能同时关注语法、语义、位置、共指等多种不同的关系。

🧮 参数量分析

💡

为什么多头比单头好？
单头注意力的平均 pooling 效应会稀释多样性信息。多个头各自关注不同的表示子空间： 有的头关注相邻词（局部语法），有的头关注远距离实体（共指消解）， 有的头关注语义角色（主谓宾关系）。原论文的可视化实验证实了不同头确实学到了互补的注意力模式。

5. Masked Attention & Cross-Attention — 解码器的两种注意力

Decoder 中包含两种注意力机制：Masked Multi-Head Self-Attention（保证自回归性质） 和 Cross-Attention（Encoder-Decoder Attention）（桥接编码器和解码器）。 理解这两种注意力的区别是理解 Transformer 生成过程的关键。

🔒 Masked Self-Attention

🌉 Cross-Attention

💡

关键区别：
Masked Self-Attention：Q, K, V 都来自 Decoder 自身输入，但通过上三角 mask（-∞） 阻止位置 i 关注位置 j (j > i)，保证自回归生成时不会"偷看未来"。
Cross-Attention：Q 来自 Decoder 上一层的输出，K 和 V 来自 Encoder 的最终输出。 Decoder 的每个位置可以关注 Encoder 的所有位置（无 mask），让生成过程能"查阅"输入序列的完整上下文。 这是 Seq2Seq 模型中标准 Attention 的 Transformer 版本。

6. Position-wise Feed-Forward Network — 位置级前馈网络

每个 Encoder/Decoder 层在 Attention 之后都有一个全连接前馈网络。 它是 Position-wise 的——对每个位置独立地应用相同的两层 MLP（参数共享）， 但在不同位置之间没有交互。这个设计让 Attention 负责token 间交互， FFN 负责单个 token 内部的特征变换（升维→激活→降维）。

🔑 FFN 的作用与动机

💡

Attention + FFN = 双阶段处理：
Attention 是"交流"阶段：每个 token 从其他 token 聚合上下文信息。
FFN 是"思考"阶段：每个 token 独立地对聚合后的表示进行非线性变换。
这种设计分离了token 间交互和token 内处理两个职责，是 Transformer 优雅架构的关键。 现代 LLM 中 FFN 存储了大量事实知识（有研究显示 FFN 相当于 Key-Value 记忆）。

7. Add & Norm — 残差连接与层归一化

每个子层（Attention 和 FFN）之后都有 Add（残差连接）和 LayerNorm（层归一化）。 残差连接让梯度能直接流过深层网络，解决深层 Transformer 的训练困难； LayerNorm 对每个样本的特征维度进行归一化，稳定训练、加速收敛。

📐 Add & Norm 公式 + LayerNorm 定义

💡

Post-Norm vs Pre-Norm：
原论文使用 Post-Norm（先子层再归一化），但深层网络训练不稳定，需要学习率 warmup。 现代模型（GPT-2/3/4、LLaMA）普遍使用 Pre-Norm（先归一化再子层），训练更稳定， 可以去掉 warmup。代价是 Pre-Norm 的残差累积使深层表示更接近输入，等效深度略浅， 但有研究通过更好的初始化弥补了这一问题。LayerNorm 在特征维度上归一化（不像 BatchNorm 在 batch 维度）， 适合变长序列和 NLP 场景。

8. 训练与推理 — Teacher Forcing · Autoregressive · KV Cache

Transformer 在训练和推理时的行为有本质区别。训练时使用 Teacher Forcing 并行计算所有位置；推理时自回归逐个生成 token， 并使用 KV Cache 避免重复计算。

🎓 Teacher Forcing

⚡ KV Cache 原理

💡

KV Cache 为什么重要？
在自回归生成中，第 t 步需要计算所有 ≤t 位置的 Attention。如果不缓存， 每个新 token 都要重新计算之前所有 token 的 K 和 V——计算量从 O(n²) 膨胀到 O(n³)。 KV Cache 将每个位置的 K/V 向量保存下来，新 token 只需计算自己的 Q、K、V， 然后与缓存中的所有 K/V 做 Attention。这样总计算量保持 O(n²)， 是 LLM 推理效率的关键优化。现代推理框架（vLLM、TensorRT-LLM） 的核心技术之一就是高效的 KV Cache 管理（PagedAttention 等）。

长文本扩展 通过稀疏/线性注意力 RoPE + 窗口/外推 同 BERT + GPT
当前趋势 逐渐被 Enc-Dec 和 Dec-only 替代 LLM 绝对主流 多任务 + 多语言场景
🧭

为什么 Decoder-Only 成为 LLM 主流？
1. 统一性：所有任务都可以表示为"给定前缀预测下一个 token"，Prompt/Instruction 天然适配。
2. 扩展性：Causal Attention 的稀疏性可被 FlashAttention 等优化利用，训练和推理效率更高。
3. 涌现能力：In-Context Learning、Chain-of-Thought 等能力在 Decoder-only 模型中更易涌现。
4. 简单性：无需 Encoder，架构更简洁，工程实现和维护成本更低。

10. 总结 — Transformer 核心创新与设计精髓

Transformer 的成功不仅在于其性能，更在于其架构设计的优雅—— 通过几个简单而强大的组件组合，实现了对序列数据的全新建模范式。

Transformer 的设计精髓：
1. 职责分离：Attention 负责"交流"（token 间交互），FFN 负责"思考"（token 内变换），LayerNorm 负责"稳定"，残差负责"流动"。
2. 对称与统一：Encoder 和 Decoder 使用相同的子层结构，仅 Attention 的 mask 和 Q/K/V 来源不同。
3. 可扩展性：堆叠更多层（深度）、更多头（宽度）、更大 d_model（容量）即可获得更好的性能，Scaling Law 驱动了 LLM 时代。
4. GPU 友好：大量矩阵乘法（而非逐元素操作）天然适合 GPU 并行计算。

📋 Transformer & BERT 面试题精讲

涵盖 Transformer 基础、注意力机制、BERT 模型、大模型通用知识，点击展开答案

🔷 Transformer 基础
1. Transformer 整体结构是怎样的？它对行业产生了哪些影响？ ▼
结构：由编码器(Encoder)和解码器(Decoder)堆叠而成。Encoder 每层包含多头自注意力、前馈网络；Decoder 额外增加编码器-解码器注意力；全链路搭配残差连接、层归一化。

影响：摒弃RNN串行结构，依靠自注意力实现序列并行计算，大幅提升长距离依赖建模能力，成为NLP、CV等领域主流架构。
2. Transformer 相比 RNN/LSTM 有哪些优势？ ▼
• 可并行计算，训练速度远高于串行的RNN/LSTM；
• 自注意力直接计算序列任意位置依赖，彻底缓解长序列梯度消失问题；
• 全局建模能力更强。
3. 多头注意力（Multi-Head Attention）有什么作用？ ▼
将Q/K/V拆分为多组独立头，从不同语义子空间提取特征，丰富模型表达能力；多头输出拼接后通过线性层自适应融合权重。
4. 缩放点积注意力为什么要除以 √dₖ？代码如何实现？ ▼
缩放原因：高维向量点积后数值易过大，进入softmax梯度饱和区，除以√dₖ将分布归一化，保证梯度有效。
替代方案：使用Xavier等优秀参数初始化（如T5），从源头控制数值范围。

NumPy 简易实现：
def scaled_dot_product_attention(Q, K, V):
  dk = K.shape[-1]
  scores = np.dot(Q, K.T) / np.sqrt(dk)
  weights = softmax(scores)
  return np.dot(weights, V), weights
5. 如何平衡 Transformer 的性能与算力？ ▼
调整网络层数、隐藏维度；使用稀疏注意力、混合精度训练、模型量化；采用长序列专用Transformer变体（如Longformer、Reformer）。
6. 自注意力是如何实现并行计算的？ ▼
注意力核心为矩阵乘法，GPU/TPU可对矩阵运算高度并行，序列所有位置同步计算依赖关系。时间复杂度为 O(n²d)，其中n为序列长度，d为向量维度。
7. 位置编码（Position Encoding）的作用是什么？ ▼
自注意力本身无位置感知能力，位置编码为每个位置添加独有特征，让模型学习语序、时序信息。原版Transformer使用固定正弦余弦位置编码；BERT使用可学习位置编码。
8. 如何处理变长序列输入？ ▼
采用 Padding 补齐序列，搭配Padding Mask屏蔽无效占位符，确保模型不会关注到填充位置。
9. 超长序列有哪些优化方案？ ▼
分块注意力（Chunked Attention）、稀疏注意力（Sparse Attention）、记忆压缩（Memory Compression）、长序列专用模型（Longformer/Reformer）。FlashAttention 通过优化GPU内存读写也能显著提升长序列效率。
10. 多尺度表示是如何实现的？ ▼
依靠多头注意力机制，不同头捕捉不同尺度、不同类型的序列特征。有的头关注局部语法，有的头关注长距离语义依赖。
11. 计算效率与表达能力如何权衡？ ▼
矩阵并行提升效率，多头设计增强表达；通过调整注意力头数（如8/16/32头）、隐藏维度（如512/768/1024）来完成权衡。
12. 参数共享会带来什么影响？ ▼
减少参数量、抑制过拟合，提升多任务泛化能力。ALBERT 通过跨层参数共享实现模型压缩，但会牺牲一定表达能力。
13. Encoder 与 Decoder 有什么区别？ ▼
• Encoder：仅含自注意力+前馈，负责编码输入全局特征；
• Decoder：包含掩码自注意力、编码-解码注意力、前馈，用于序列生成。
Decoder 的掩码自注意力使用因果掩码（Causal Mask），防止当前位置看到未来信息。
14. 前馈网络（FFN）在 Transformer 中起什么作用？ ▼
对注意力输出做非线性变换：
• 引入非线性（注意力本质是线性加权，Softmax只在权重上非线性）
• 升维再降维：d_ff ≈ 4×d_model，在更高维度空间分离和重组特征
• 知识存储：研究表明FFN的W₂矩阵相当于Key-Value记忆，存储了大量事实型知识
15. Pre-norm 与 Post-norm 有什么区别？ ▼
• Post-norm（原生Transformer）：残差相加后做归一化，Output = LayerNorm(x + SubLayer(x))
• Pre-norm（BERT主流）：先归一化再进入注意力/FFN，Output = x + SubLayer(LayerNorm(x))
Pre-norm 在深层网络训练中更稳定，梯度流动更顺畅，现代大模型普遍采用。
16. Transformer 有哪些防过拟合手段？ ▼
Dropout、L2权重衰减、标签平滑（Label Smoothing）、残差连接（同时缓解梯度消失）。
17. Transformer 中两类 Mask 分别是什么？ ▼
• Padding Mask：屏蔽补齐的无效占位符，防止模型关注padding位置；
• Causal Mask（因果掩码）：Decoder 专用，屏蔽未来位置，防止信息泄露。是一个上三角为-∞的下三角矩阵。
18. Layer Norm 的作用是什么？为什么 NLP 不用 Batch Norm？ ▼
LN作用：对单个样本所有特征归一化，稳定输入分布、缓解梯度消失、加速训练。

为什么不用BN：BN基于批次样本归一化，适配CV（图像尺寸固定）；NLP序列长度不固定，同一样本内特征强关联，BN会破坏语义结构，因此NLP主流用LN。
19. Encoder 与 Decoder 之间是如何交互的？ ▼
Decoder 的编码-解码注意力层（Cross-Attention）中，Query 取自解码器上一层输出，K/V 取自编码器最终输出。这样每个解码位置都能关注到编码器的全部上下文信息，实现输入与输出的融合。
20. 自注意力的时间复杂度是多少？ ▼
设序列长度 n，向量维度 d，标准自注意力复杂度为：O(n²d)。其中 QKᵀ 计算为 O(n²d)，加权求和为 O(n²d)。这也是长序列处理的瓶颈所在。
🔷 注意力优化方向
1. 如何提升注意力计算效率？ ▼
• 稀疏注意力：将复杂度从 O(n²d) 降为 O(nd)；
• FlashAttention：优化GPU内存读写开销，利用Tiling和重计算减少HBM访问；
• 多查询注意力(MQA)：所有头共享K/V，仅保留独立Q，降低显存与带宽消耗；
• 分组查询注意力(GQA)：介于MHA和MQA之间，多组共享K/V。
2. 注意力权重有可解释性吗？ ▼
是的，注意力权重直观体现模型重点关注的词/区域，可用于分析模型决策逻辑。但需要注意：高注意力不一定等于高重要性，因为后续FFN层会进一步变换。
3. 如何平衡局部与全局信息？ ▼
结合全局注意力（捕捉长距离依赖）+ 局部/窗口注意力（捕捉局部语法、降低算力）。典型应用如 Longformer 的滑动窗口+全局注意力组合。
4. 主流注意力变体有哪些？ ▼
多头注意力（MHA）、自注意力（Self-Attention）、交叉注意力（Cross-Attention）、局部注意力（Local Attention）、层次化注意力（Hierarchical Attention，适配文档、分层文本）、FlashAttention、MQA、GQA。
5. 什么是层次化注意力？ ▼
针对文档、段落等结构化数据，分层计算注意力：先在词级别计算注意力得到句子表示，再在句子级别计算注意力得到文档表示，逐层聚合信息。
🔷 BERT 模型
1. BERT 的模型结构是怎样的？ ▼
纯 Transformer Encoder 堆叠，采用双向注意力（无因果掩码），预训练任务为：
• MLM（掩码语言模型）：随机遮盖15% token让模型预测，学习双向语义；
• NSP（句子关系预测）：判断两句话是否为连续文本（后续RoBERTa证明NSP效果有限）。
2. BERT 的三大 Embedding 为什么可以相加？ ▼
Token Embedding（词义）、Segment Embedding（句子区分）、Position Embedding（位置）对应不同"信号频率"，神经网络具备解耦能力；神经元本身就是加权求和运算，叠加不会造成不可逆信息损失。三者维度相同（如768维），直接相加后送入Encoder。
3. BERT 使用什么样的位置编码？ ▼
采用可学习位置编码（Learned Position Embedding），参数随训练更新；原生Transformer则使用固定的正弦/余弦位置编码。
4. 子词分词（WordPiece/BPE）有什么作用？ ▼
解决OOV（词表外词汇）问题，将生词拆分为子词，依靠子词语义推断。例如 "unhappily" → ["un", "happ", "ily"]。中文多采用字符级分词，彻底规避词级OOV。
5. [CLS] 符号有什么作用？有哪些替代方案？ ▼
作用：句首特殊标记，聚合整句语义，用于文本分类等句子级任务。
替代方案：对所有词向量做最大池化/平均池化，将池化结果作为句子表示。
6. BERT 中有哪些 Mask？ ▼
• MLM Mask：预训练时随机掩码15%的token（80%替换为[MASK]，10%替换为随机词，10%保持不变），让模型预测被掩盖的词；
• Padding Mask：屏蔽填充位，防止模型关注无效位置。
7. BERT 与 GPT 的核心区别是什么？ ▼
• BERT：Encoder-only、双向注意力，擅长理解类任务（分类、抽取、QA）；
• GPT：Decoder-only、单向因果掩码、自回归生成，擅长生成类任务。
这是两种不同的范式选择，现代大模型（如GPT-4、LLaMA）大多采用Decoder-only架构。
8. BERT 如何处理一词多义？ ▼
依靠自注意力机制+MLM预训练，单词根据上下文动态调整向量表示。同一个"苹果"在不同句子中会产生不同的向量，这是静态词向量（如Word2Vec）无法做到的。
9. ALBERT 的模型压缩方案及缺陷？ ▼
压缩方案：
① 跨层参数共享（所有层共享同一套参数）；
② 嵌入层因式分解（先映射到低维E再升维到H，参数量从 V×H 降为 V×E + E×H）。

缺陷：模型表达能力下降，推理速度无明显提升（计算量未减少）。
10. BERT 有哪些缺陷？有哪些改进模型？ ▼
缺陷：输入长度受限（512 tokens）、长序列算力高（O(n²)）、NSP任务效果一般。

改进模型：
• RoBERTa：移除NSP、动态掩码、增大数据与batch size、更长训练；
• Longformer：窗口注意力+全局注意力，支持长文档；
• DeBERTa：解耦注意力（内容+位置分开计算）。
11. RoBERTa 相比 BERT 做了哪些改进？ ▼
① 移除NSP任务（证明它对下游任务帮助有限）；
② 使用动态掩码（每个epoch对同一序列生成不同mask）；
③ 扩充训练数据（160GB文本）与增大batch size（8K）；
④ 训练更长时间，使用更大的学习率。
12. BERT 如何缓解梯度消失？ ▼
残差连接 + Layer Norm：残差连接让梯度可以直接跨层传播（梯度高速公路），Layer Norm 稳定每层输入分布，两者配合保证梯度在深层网络正常流通。
🔷 大模型通用知识点
1. 主流大模型架构有哪些分类？ ▼
• Decoder-only：GPT、LLaMA — 生成任务主流；
• Encoder-only：BERT — 理解任务；
• Encoder-Decoder：T5、BART — 翻译、文本转换；
• 混合架构：GLM — 结合双向与单向注意力。
2. Prefix LM 与 Causal LM 有什么区别？ ▼
核心差异在掩码方式：
• Causal LM：严格单向掩码，每个位置只能看到之前的token；
• Prefix LM：前缀部分双向可见（类似Encoder），仅生成区单向掩码（类似Decoder）。
3. RLHF 的完整流程是怎样的？ ▼
三步流程：
1. 监督微调(SFT)：用人类指令数据微调基座模型，让模型学会遵循指令；
2. 训练奖励模型(RM)：人工对多个回答打分排序，训练模型输出奖励值；
3. PPO强化学习：以奖励模型为目标，使用PPO算法优化策略，同时加入KL散度约束（防止模型退化，偏离SFT模型太远）。
4. Instruction Tuning 与 Prompt Learning 有何不同？ ▼
• Prompt Learning：设计提示词模板，不改动模型参数，适配小样本场景；
• Instruction Tuning：用海量指令数据微调模型，让模型理解多样化指令，适配零样本泛化。
5. LoRA 低秩微调的原理是什么？有哪些关键超参？ ▼
原理：冻结原模型权重W，新增低秩分支 ΔW = BA（A降维、B升维），仅训练A、B矩阵。前向传播：h = Wx + BAx。B初始化为0保证训练开始时等效于原模型，A高斯初始化。

超参：秩r常用8/16，Alpha固定16（缩放因子α/r），学习率约1e-4。
对比全参微调：显存开销极低（仅训练0.1%~1%参数），劣势是极端分布外数据效果偏弱。
6. P-Tuning 与 P-Tuning v2 有什么区别？ ▼
• P-Tuning v1：仅在输入层添加可学习Prompt（连续向量），通过LSTM/MLP编码后拼接到输入；
• P-Tuning v2：在每一层都添加可学习Prompt（Deep Prompt Tuning），移除重参数模块，支持更多任务类型（如序列标注）。
7. 如何训练领域大模型？有哪些关键注意事项？ ▼
预训练数据：优先论文、书籍等高质量领域文本。
缓解灾难性遗忘：领域数据:通用数据 ≈ 1:5~1:10，降低微调学习率。
基座选择：数据量 < 1万条选Chat模型（已有指令跟随能力），> 10万条选Base模型（从头适配更灵活）。
8. LLM "复读机"问题是什么？如何解决？ ▼
现象：模型在生成时不断重复相同语句。
成因：训练数据重复、自回归训练特性（错误累积）、解码策略问题（贪婪解码易陷入循环）。
解决：数据去重、调高温度参数、增大Beam宽度、开启重复惩罚（repetition_penalty）、文本后处理去重。
9. 如何扩充 LLaMA 的中文词表？ ▼
1. 用中文语料训练SentencePiece扩充词表（增加常用中文字词）；
2. 初始化新增token的embedding向量（可用已有中文token均值初始化）；
3. 进行二次预训练/SFT适配新词表，让模型学会使用新token。
