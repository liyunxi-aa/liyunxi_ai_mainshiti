🎲 神经网络参数初始化方法

涵盖 17 种方法: Xavier/Glorot · He/Kaiming · LeCun · Orthogonal · Sparse · Truncated Normal · Constant · Identity · Normal · Uniform · Normed · Fixup — 交互式对比可视化

🔑 为什么参数初始化至关重要？

权重初始化决定了网络训练的起点。糟糕的初始化会导致梯度消失、梯度爆炸或对称性问题，使网络无法学习。 好的初始化保持各层激活值和梯度的方差稳定，让信息在网络中顺畅流动。

💀 梯度消失

权重太小 → 激活值逐层缩小 → 梯度趋近于 0 → 深层网络无法学习。Sigmoid/Tanh 激活下尤为严重。

💥 梯度爆炸

权重太大 → 激活值逐层放大 → 梯度指数增长 → 参数更新过大，loss 变成 NaN。

🔁 对称性问题

所有权重初始化为相同值（如全 0）→ 同层神经元计算相同输出 → 梯度相同 → 退化为等效单神经元。

📐 核心目标：保持方差稳定

💡 核心直觉

He 初始化专为 ReLU 设计，因为 ReLU 会"杀死"一半的神经元（负半轴输出为 0）， 所以 He 初始化的方差比 Xavier 大 2 倍，以补偿 ReLU 造成的方差减半效应。

📚 各方法详解

以下是实践中最重要的参数初始化方法。每种方法都有特定的适用场景和数学推导。

🎓 Xavier / Glorot 初始化 (2010)

核心思想：保持前向传播和反向传播的方差一致。
推导假设：线性激活函数，且权重与输入独立。
Uniform 范围： $[-\sqrt{\frac{6}{n_{in}+n_{out}}}, +\sqrt{\frac{6}{n_{in}+n_{out}}}]$
Normal 标准差： $\sigma = \sqrt{\frac{2}{n_{in}+n_{out}}}$
适用激活： Tanh、Sigmoid、Linear（效果最好）；不适用 ReLU。
PyTorch： nn.init.xavier_uniform_() / nn.init.xavier_normal_()

🏆 He / Kaiming 初始化 (2015)

核心思想：针对 ReLU 激活函数的修正 — ReLU 使一半输出为 0，方差减半。
Uniform 范围： $[-\sqrt{\frac{6}{n_{in}}}, +\sqrt{\frac{6}{n_{in}}}]$
Normal 标准差： $\sigma = \sqrt{\frac{2}{n_{in}}}$ （注意分母只有 $n_{in}$，无 $n_{out}$）
适用激活： ReLU 及变体（Leaky ReLU、PReLU）。
PyTorch： nn.init.kaiming_uniform_() / nn.init.kaiming_normal_()
变体： a 参数为 Leaky ReLU 负斜率，默认 0 (ReLU)。

📜 LeCun 初始化 (1998)

核心思想：最早的方差缩放方法，比 Xavier/He 更早提出。假设激活函数在 0 附近近似线性。
Uniform 范围： $[-\sqrt{\frac{3}{n_{in}}}, +\sqrt{\frac{3}{n_{in}}}]$
Normal 标准差： $\sigma = \sqrt{\frac{1}{n_{in}}}$
适用激活： Tanh、SELU（SELU 配合 LeCun Normal 使用）。
PyTorch： nn.init.lecun_uniform_() / nn.init.lecun_normal_()
与 He 的关系： He 的方差是 LeCun 的 2 倍（为 ReLU 补偿）。

🔷 Orthogonal 正交初始化

核心思想：权重矩阵为正交矩阵（$W^T W = I$），使各层输出方差完全保持为输入方差。
实现方式：生成随机矩阵后进行 QR 分解或 SVD，取正交部分。
适用场景： RNN/LSTM（缓解梯度消失/爆炸）、深度线性网络。
PyTorch： nn.init.orthogonal_()
变体：可以乘以 $\sqrt{gain}$ 调整输出方差幅度。

🕸️ Sparse 稀疏初始化

核心思想：每个神经元只连接 $k$ 个输入，其余权重为 0。灵感来自生物神经网络的稀疏连接。
实现方式：随机选择 $k$ 个连接赋非零值（通常用正态分布），其余置零。
典型稀疏度： $k = 10 \sim 100$ 或 $k = \log_2(n_{in})$。
适用场景： 大型嵌入层、超大网络、模仿生物稀疏性。
PyTorch： nn.init.sparse_()

❌ Zero 初始化（反面教材）

为什么不行？所有权重相同 → 所有神经元产生相同的输出和相同的梯度 → 对称性无法打破。
例外：偏置（bias）可以初始化为 0，因为权重已经打破了对称性。
特殊情况：某些归一化层的 scale/bias 参数可初始化为 0（如 BatchNorm 的 $\gamma=1, \beta=0$）。

✂️ Truncated Normal 截断正态分布

核心思想：从正态分布采样，但丢弃超过 ±2σ 的值重新采样，避免极端值导致的不稳定。
标准差： 通常采用 Xavier 或 He 的标准差。
适用场景： TensorFlow/Keras 的默认初始化（glorot_uniform 的替代是 TruncatedNormal）。
优点： 去除了长尾，使初始训练更稳定，尤其在使用较大学习率时。
PyTorch： nn.init.trunc_normal_() (PyTorch 1.10+)

📊 Standard Normal / Uniform

标准正态 N(0,1)：方差 = 1，不考虑 fan_in/fan_out → 深层网络极易梯度爆炸。
标准均匀 U[-1,1]：方差 = 1/3 ≈ 0.333，无理论依据，仅适用于极浅层网络。
使用建议： 几乎不推荐直接使用。至少要乘以 $\frac{1}{\sqrt{n_{in}}}$ 缩放。
例外： 某些非常浅的模型（如逻辑回归）或调试阶段可用。
PyTorch： nn.init.normal_() / nn.init.uniform_()

🔧 Constant 常量初始化

核心思想：所有权重初始化为相同常量 $c$。
问题：与 Zero Init 类似，同样导致对称性问题——所有权重在同一梯度方向更新。
适用场景：基本不用于权重初始化，常用于偏置初始化（如 Forget Gate Bias = 1）。
LSTM 中： 遗忘门偏置常初始化为 1，迫使模型初始时保留更多信息。
PyTorch： nn.init.constant_()

🪞 Identity 恒等初始化

核心思想：$W = I$（或广义单位阵），输出 = 输入 + 微小扰动。网络初始行为等同于恒等映射。
适用场景： ResNet 风格跳跃连接、循环神经网络、可逆网络、Normalizing Flows。
优点： 深层网络初始时等价于浅层网络，梯度能高效回传。
变体： W = I + small_noise 用于打破对称性。
PyTorch： nn.init.eye_() 或手动 torch.eye()

🎯 L2-Normalized 归一化初始化

核心思想：每个神经元的权重向量 L2 范数 = 1，即 $\|W_i\|_2 = 1$。
等价于： 使每个神经元初始输出方差 ≈ 输入方差（不膨胀也不衰减）。
适用场景： 度量学习（Siamese/Triplet 网络）、对比学习、嵌入层、自编码器。
与正交初始化的关系： 正交初始化同时约束不同神经元之间的方向正交，而 L2-Normed 只约束模长。
实现： W = random(); W = W / ||W||_2

🔩 Fixup / Zero-Center 初始化 (2019)

核心思想：通过精心设计的初始化方案，无需 BatchNorm 即可训练 10,000 层深层网络。
规则： (1) 最后一层分类头初始化为 0；(2) 残差分支中最后一个 BN/Conv 初始化为 0；(3) 偏置和缩放因子设特定值补偿 ReLU 的均值偏移。
适用场景： 极深 ResNet、无归一化层训练、分布式训练（避免 BN 跨卡同步开销）。
相关方法： SkipInit、ReZero（最后一层初始化为 0 的思想）、ZOOPS。
论文： Zhang et al., "Fixup Initialization: Residual Learning Without Normalization", ICLR 2019

🎯 选择指南

不同架构和激活函数下，如何选择最合适的初始化方法。

🧠 CNN / ResNet / ViT

→ He/Kaiming Normal（默认标配）
ReLU 家族 + He Init = 工业界最广泛的组合。
ResNet 论文明确使用 He 初始化。
PyTorch 中 Conv2d 默认即 Kaiming Uniform。

🔤 Transformer / Attention

→ Xavier Uniform 或 He Normal
BERT/GPT 多使用 Xavier/Normal(0, 0.02)。
注意力层无 ReLU → Xavier 合适。
PyTorch 中 nn.Linear 默认 Kaiming Uniform。

🔄 RNN / LSTM / GRU

→ Orthogonal 初始化（权重矩阵）
正交矩阵保持范数，缓解梯度消失/爆炸。
输入→隐层可用 Xavier。
PyTorch LSTM 默认采用 Uniform(-√k, √k)。

⚡ SELU 网络 (SNN)

→ LeCun Normal（唯一正确选择）
SELU 的自归一化性质依赖 LeCun 初始化。
使用其他初始化会破坏自归一化特性。

📊 GAN / 生成模型

→ Normal(0, 0.02)（DCGAN 风格）
DCGAN 论文推荐 N(0, 0.02)。
也可用 Xavier Normal。
BigGAN 等大模型使用 Orthogonal。

⚠️ 常见错误

→ 用 Xavier + ReLU ← 方差会逐渐衰减
→ 用 He + Tanh ← 方差会逐渐膨胀
→ 忘记设置 gain 参数
→ 所有层用同一 std，忽略 fan 差异
→ bias 初始化过大（应设为 0）

💻 PyTorch 实战代码

在 PyTorch 中如何正确使用各种初始化方法。

🔧 单层手动初始化

import torch.nn as nn
import torch.nn.init as init

linear = nn.Linear(256, 128)

# Xavier / Glorot
init.xavier_uniform_(linear.weight)
init.xavier_normal_(linear.weight)

# He / Kaiming
init.kaiming_uniform_(linear.weight, mode='fan_in', nonlinearity='relu')
init.kaiming_normal_(linear.weight, mode='fan_in', nonlinearity='relu')

# LeCun
init.lecun_uniform_(linear.weight)
init.lecun_normal_(linear.weight)

# Truncated Normal (PyTorch 1.10+)
init.trunc_normal_(linear.weight, std=0.02, a=-0.04, b=0.04)

# Orthogonal
init.orthogonal_(linear.weight)

# Identity (方阵) / Eye
init.eye_(linear.weight)

# Sparse
init.sparse_(linear.weight, sparsity=0.9, std=0.01)

# Standard Normal / Uniform
init.normal_(linear.weight, mean=0, std=1)
init.uniform_(linear.weight, a=-1, b=1)

# Constant (weight: 不推荐; bias: 常用)
init.constant_(linear.weight, 0.1)
init.zeros_(linear.bias)    # Bias 始终初始化为 0

📦 通用初始化函数（遍历所有层）

def init_weights(model, method='he'):
    for m in model.modules():
        if isinstance(m, (nn.Linear, nn.Conv2d)):
            if method == 'xavier':
                init.xavier_uniform_(m.weight)
            elif method == 'he':
                init.kaiming_normal_(
                    m.weight, mode='fan_in',
                    nonlinearity='relu')
            elif method == 'orthogonal':
                init.orthogonal_(m.weight)
            if m.bias is not None:
                init.zeros_(m.bias)

# 使用
model = MyModel()
model.apply(init_weights)

⚠️ gain 参数 — 根据激活函数调整方差
