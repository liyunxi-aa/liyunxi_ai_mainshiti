1. 最大间隔分类器（Hard Margin）

SVM 的核心思想：在所有能正确分类的超平面中，找到使间隔（margin）最大化的那一个。 离决策边界最近的点称为支持向量（Support Vectors），它们定义了间隔的宽度。拖拽数据点观察边界如何变化。

2. 软间隔 SVM（Soft Margin）与参数 C

现实数据往往不可完美线性分离。软间隔 SVM 引入松弛变量 ξᵢ，允许部分点违反间隔约束。 正则化参数 C 控制间隔宽度与误分类容忍度之间的权衡。

3. 核方法（Kernel Trick）

线性 SVM 无法处理非线性可分数据。核技巧将数据隐式映射到高维空间，在高维空间中找到线性决策边界， 在原空间中表现为非线性边界。RBF 核 K(x, x′) = exp(−γ‖x − x′‖²) 是最常用的核函数之一。

4. Hinge Loss 与分类损失对比

SVM 的损失函数是 Hinge Loss：L(y, f(x)) = max(0, 1 − y·f(x))。当样本被正确分类且离边界足够远（margin ≥ 1）时损失为 0。 与其他分类损失（Logistic Loss、0-1 Loss）相比，Hinge Loss 具有稀疏性——多数正确分类的样本不贡献梯度。
