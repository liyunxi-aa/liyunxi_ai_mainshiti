🧩 MoE · 混合专家模型

条件计算 + 稀疏激活：每个 Token 只激活一小部分专家，在参数总量爆炸式增长的同时保持推理成本可控

1. 什么是混合专家模型 (MoE)？

MoE 是一种条件计算 (Conditional Computation) 架构：模型包含 N 个独立的"专家"子网络， 每个 Token 经由门控路由器 (Router/Gate) 动态选择 Top-K 个专家 参与计算。 最终输出是各专家输出的加权求和。核心优势：参数量可以极大扩展而推理 FLOPs 几乎不变。

📐 MoE 核心公式

💡 核心直觉：想象一个由 N 位专家组成的委员会。每个问题 (Token) 到达时，门控路由器判断"谁最擅长回答这个问题"， 只派给 Top-K 个最相关的专家。最终答案 = 各专家意见的加权综合。大部分专家保持沉默 → 激活的参数量远小于总参数量，这就是"稀疏激活"的精髓。

2. 门控路由器 (Router) — 谁来决定分配？

路由器本身是一个可学习的线性层 Wg ∈ Rd×N：输入 Token 表示 x， 输出 N 个 logits，经 Softmax + Top-K 截断 后得到稀疏的门控权重。 Softmax 前的 logits 还可叠加 可学习的偏置 / 噪声 鼓励探索。

📐 门控函数 G(x)

💡 Top-K 截断是关键：Softmax 本身不稀疏（所有 N 个专家都有非零权重）， Top-K 强制只保留最大的 K 个值并置零其余 → 实现真正的稀疏计算。 K=1 最节省计算但可能限制容量；K=2 是当前主流选择。加噪声（Gating Noise） 帮助路由器在训练初期探索不同的专家组合，避免过早陷入局部最优。

3. 专家网络 — 每个专家是什么？

在 Transformer MoE 中，每个专家通常是一个标准的前馈网络 (FFN)， 与密集模型的 FFN 结构相同，但不同专家学习不同的知识分布。 现代 MoE 中常使用 SwiGLU 激活函数。专家可以分为 路由专家 (Routed) 和 共享专家 (Shared) 两类。

📐 单个专家 & SwiGLU 激活

路由专家 (Routed) 共享专家 (Shared) 门控权重 Wg
💡 共享专家 (DeepSeek-MoE 创新)：传统 MoE 所有专家都是路由的。 DeepSeek-MoE 提出：设置少量"共享专家"，每个 Token 必定通过， 负责捕获通用知识；路由专家则专注各自领域。这解决了"某些通用知识被分散到不同专家中"的问题， 同时避免路由专家在通用知识上的冗余。

4. 负载均衡 — MoE 最核心的工程挑战

路由器可能"偏爱"少数专家 → 热门专家过载、冷门专家闲置 → 计算资源浪费、训练不稳定。 为此需要辅助损失 (Auxiliary Loss) 和 专家容量 (Expert Capacity) 机制。 理想情况下每个专家处理的 Token 数应均匀分布。

📐 负载均衡辅助损失 & 容量

💡 路由坍塌 (Routing Collapse)：最需要警惕的失败模式。 路由器学到"所有 Token 都发给 1-2 个专家"——模型退化为密集模型，完全损失 MoE 的优势。 辅助损失 + 容量强制 + Router Z-Loss 三者合力防止坍塌。容量因子 C 控制每个专家 最多处理的 Token 数：超出容量的 Token 被"溢出"到下一层或直接丢弃 (Token Dropping)。

5. MoE vs 密集模型 — 对比分析

MoE 和密集模型在不同维度上各有优劣。理解这些 trade-off 是正确使用 MoE 的前提。

维度 密集模型 (Dense) MoE 稀疏模型
总参数量 较小（如 7B） 极大（如 8×7B MoE）
每 Token 激活参数量 = 总参数量 ≈ 总参数 / N × K（如 2×7B）
每 Token FLOPs 固定，与参数量正比 远小于总参数量对应的 FLOPs
推理延迟 低（无路由开销） 中等（路由 + all-to-all 通信）
训练稳定性 高 较低（需负载均衡 + Z-Loss）
显存占用（推理） 中等 高（所有专家均需加载）
知识容量 受限于参数量 极大（不同专家专精不同领域）
微调难度 简单 中等（需注意专家利用率）
分布式训练通信 仅 All-Reduce 额外 All-to-All（专家并行）
💡 Best of both worlds：DeepSeek-V3 等架构采用 MoE + 多头潜在注意力 (MLA) 的组合—— 注意力部分保持密集（低开销），FFN 部分使用 MoE 扩展知识容量。这种"密集注意力 + 稀疏 FFN"已成为 主流大模型的设计范式，兼顾推理效率与知识广度。

6. 知名 MoE 模型一览

从 2017 年的稀疏门控 MoE 到 2024 年的 DeepSeek-V3，MoE 已从学术概念走向大规模工业部署。

🔮 Mixtral 8×7B

8 专家Top-247B 总参

Mistral AI 2023 发布。8 个 FFN 专家，每次激活 2 个，激活参数 ~13B。 在多数 benchmark 上超越 LLaMA 2 70B，推理速度接近 7B 密集模型。证明了 MoE 在中等规模的实用性。

🐋 DeepSeek-V2 / V3

256 专家Top-8共享专家

DeepSeek 2024。引入 共享专家 (Shared Expert) + 细粒度专家切分： 256 个路由专家 + 2 个共享专家，Top-8 激活。配合 MLA 注意力，实现了极高的训练效率和推理性能。 V3 总参数 671B，激活 ~37B。

⚡ Switch Transformer

2048 专家Top-11.6T 总参

Google 2021。将 Top-K 推到极致：K=1，每个 Token 只激活一个专家。 简化了路由、减少了通信，以 2048 专家验证了 MoE 的超大规模可能性。 引入 capacity factor 处理溢出。

🧠 GLaM

64 专家Top-21.2T 总参

Google 2021。64 个专家每层，Top-2 激活，总参 1.2T，激活 ~97B。 训练效率：用 GPT-3 1/3 的 FLOPs 达到更优性能。验证了 MoE 在训练成本上的巨大优势。
